# Reference Assets

Place shared standards and project reference material here.

Expected layout:

- `CDISC/ADaM_IG/`
- `CDISC/SDTM_IG/`
- `CDISC/Controlled_Terminology/`
- `CDISC/Define_XML/`
- `CDISC/TAUG/`
- `CDISC/P21_Rules/`
- `company_standards/`

Do not assume these documents can be sent directly to an LLM. The product should
expose reference lookup through explicit tools and record which references were
used.
