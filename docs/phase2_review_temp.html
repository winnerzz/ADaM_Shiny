2. Schema 是什么

Schema 可以理解成“数据结构的规则说明书 + 自动检查器”。它规定对象必须有哪些字段、字段是什么类型、哪些值合法。 

DatasetState.repair_attempts 必须是 >= 0 的整数
LLMExposureConfig.mode 只能是 metadata_only / demo_rich_context / full_data_allowed
Reference ADaM evidence 不能直接支持 derivation_logic

这样 LangGraph、API、LLM 输出、fixtures、audit 文件不会各写各的格式。

5. 已修复的关键问题

  • 新增 SpecVariable 和 SpecDocument，spec 不再是完全自由 dict。
  • 新增 DatasetResultSummary，避免 StudyState 塞入完整 DatasetState。
  • 移除 human_decisions 与 approval_records 的重复职责。
  • ApprovalRecord 改为必须有 reviewed_variables 和 source_draft_spec_hash。
  • silent_pass 必须有 rule_id。
  • LLMCallRecord 增加数据暴露一致性校验。
  • metadata_only 禁止 sample rows/full data。
  • full_data_included 必须对应 full_data_allowed。
  • Artifact 增加 kind/role 和 .sas/.sas7bdat 边界校验。
  • utc_now() 改为真正 UTC。
  • 空白字符串会被 strip 后拒绝。
  • 增加 pyproject.toml。
